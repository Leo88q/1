# @guttercaps/ampergrad

Механизм «Амперград»: фрагменты магистрали, повороты и проверка пломбы квартала.

Чистый TypeScript без зависимостей и без побочных эффектов. Внутри нет ни кошелька,
ни транзакций, ни обращения к экономике GUTTERCAPS — только правила головоломки.
Полное описание контура: `docs/12-ampergrad-mechanism.md`.

## Запуск

```bash
# тесты механизма (12 кварталов канона, 10 проверок)
node --experimental-strip-types --test packages/ampergrad/test/*.test.ts
```

Никаких пакетов ставить не нужно: модуль использует встроенный тест-раннер Node.

## Контракт

```ts
import { boardFromLevel, rotate, isSolved, poweredCells, receiversPowered, nextHint, validateLevel }
  from './src/index.ts';

const board = boardFromLevel(levels[0]);   // стартовая раскладка квартала
rotate(board, 7);                          // игрок крутит ячейку по часовой
const lit = poweredCells(board);           // ячейки, куда дошёл ток
const won = isSolved(board);               // пломба: все ячейки подключены к шине
const hint = nextHint(board, levels[0].solutionRot); // подсказка: какую ячейку крутить
```

Порты фрагмента — битовая маска: **N = 1, E = 2, S = 4, W = 8**; поворот по часовой
`((m << 1) | (m >>> 3)) & 0xF`. Формы: 1 — заглушка, 3 — отвод, 5 — прямая,
7 — тройник, 15 — крест. Крест не вращается (`fixed`).

## Что внутри

| Путь | Что это |
|---|---|
| `src/tiles.ts` | маски, повороты, орбиты, канонизация |
| `src/rules.ts` | состояние квартала, связность, пломба, ходы, подсказка, проверка контента |
| `src/levels.json` | 12 кварталов канона: маски, шина, приёмники, решение, план по ходам |
| `art/manifest.json` | спрайт → маска → доворот; образцы уменьшены до 256×256 (прод — 512×512) |
| `art/tiles/props.json` | служебные детали: указатели потока, заглушки, декор |
| `art/backgrounds/` | образец фона яруса (прод — 768×1376, по два кадра на ярус) |

Поле рисуется так: в ячейку ставится спрайт по маске фрагмента, затем спрайт и маска
крутятся одинаково. Художнику нужно нарисовать деталь **в одном положении** — остальное
делает `rotate`.
