## Что это

«Амперград» — головоломка на соединение труб: квартал из фрагментов магистрали, каждый
крутится на 90°, победа — все ячейки подключены к шине. Сессия 1–3 минуты, вход без
кошелька. Предлагаем его как **отдельный контур** внутри GUTTERCAPS: визуальный язык их
(палитра, трафаретные потёки, металл), механика и контент — свои, экономика — не тронута.

Контур описан документом `docs/12-ampergrad-mechanism.md`: идентичность (pubkey через
SIWS, как в `INTERWEAVING.md`), точные правила, арт-контракт, награды (cNFT-пломбы в
нашей программе), события, три уровня встраивания, выкатка под фича-флагом и то, чего
в контуре принципиально нет (токена, стейкинга, выплат за вход, мостов ассетов).

## Что в PR

| Путь | Что это |
|---|---|
| `docs/12-ampergrad-mechanism.md` | описание контура: правила, арт, награды, события, выкатка, не-цели |
| `packages/ampergrad/src/tiles.ts` | маски портов (N=1, E=2, S=4, W=8), повороты, орбиты |
| `packages/ampergrad/src/rules.ts` | состояние квартала, связность с шиной, пломба, ходы, подсказка, проверка контента |
| `packages/ampergrad/src/levels.json` | 12 кварталов канона: маски, шина, приёмники, решение, план по ходам |
| `packages/ampergrad/test/rules.test.ts` | 10 тестов: решение собирает квартал, старт не собран, `parMoves` сходится с каноном, кресты неподвижны |
| `packages/ampergrad/art/` | манифест «спрайт → маска → доворот», образцы деталей (256×256) и фон яруса |

Модуль — чистый TypeScript без зависимостей: `node --experimental-strip-types --test
packages/ampergrad/test/*.test.ts`. Ничего не добавляется в `npm run verify`, пока
контур не включён, — специально, чтобы этот PR не мог сломать существующие гейты.

## Чего PR не делает

* Не трогает программы, казну, эмиссию и любые цифры экономики GUTTERCAPS.
* Не вводит кросс-игровых мостов и общих PDA (в `INTERWEAVING.md` их нет — и здесь не
  появляется).
* Не включает механизм по умолчанию: всё под флагом `AMPERGRAD_ENABLED`, по умолчанию off.
* Не требует кошелька для игры: подпись нужна только на клейме награды.

## Как это выглядит

Поле собирается из спрайтов манифеста: деталь трубы тянется до самого края тайла,
поэтому фрагменты соседних ячеек визуально стыкуются (шов читается как фланец).
Образцы арта в PR уменьшены вдвое — прод-спрайты 512×512 лежат в репозитории арта
«Амперграда»; при подключении отдаём их целиком или через CDN.

Скриншоты и макеты полей — в репозитории арта (кадры кварталов 3, 31, 46, 61, 75
по одному на ярус): они собраны не «на глазок», а по настоящим уровням движка.

## Как проверить

```bash
node --experimental-strip-types --test packages/ampergrad/test/*.test.ts
```

Ожидаемо: 10 тестов, 0 падений. Тесты проверяют канон контента, а не «код компилируется»:
если квартал в `levels.json` перестанет решаться заложенным решением или план по ходам
разойдётся с раскладкой — тест это покажет.
