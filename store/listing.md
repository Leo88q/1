# Листинг в dApp Store: тексты и ассеты

Всё готово к копированию в publish.solanamobile.com. Название игры и пакет:
**АМПЕРГРАД / AMPERGRAD**, `com.ampergrad.game` (debug — `com.ampergrad.game.debug`).

## Короткое описание (до 80 знаков)

Вариант A (используем в листинге):
`Поворачивай фрагменты магистрали, верни кварталам ток. 1–3 минуты.`

Вариант B (если нужен акцент на Solana):
`Головоломка о свете и памяти города. Награды — сжатые NFT.`

## Полное описание

Амперград — город внутри гигантской природной аккумуляторной горы. Свет здесь
добывают, хранят в жилах и тратят. Вы — последний практикант гильдии Ключа,
которого забыли в списке отключённых: нужно вернуть ток кварталам, ярус за ярусом.

**Правила просты.** На поле — фрагменты магистрали: колена, прямые, тройники и
перекрёстки. Тап поворачивает фрагмент по часовой стрелке, долгое удержание —
против часовой. Перекрёстки не вращаются. Квартал собран, когда все ячейки
подключены к шине питания.

**Сессия — 1–3 минуты.** Один квартал проходится за пару минут; всего 75 уровней
по пяти ярусам: Плато Первого Контакта, Ртутный ярус, Терминальный, Старый Диод
и Плавильня. Плюс ежедневный челлендж: один и тот же квартал для всех игроков,
рейтинг по числу ходов.

**Играть можно без кошелька и без токена.** Геймплей полностью офлайновый.
Кошелёк нужен только чтобы забрать награду: печати гильдии и страницы реестра
выдаются как сжатые NFT (cNFT) в сети Solana. Игрок не подписывает транзакций
и ничего не платит — минт выполняет сервер проекта.

**Что внутри:**
- 75 кварталов с именами и Codes диспетчерской (П-01 … Я-15);
- реестр города: 60 коротких записей лора, которые открываются за уровни;
- челлендж дня со стрик-сериями;
- витрина косметики: только вид — палитры кварталов, темы ярусов, источники,
  печати. Никакой косметики, влияющей на игру.

**Честно о наградах:** это не «заработай токен». Награды — коллекционные
достижения, они не продаются и не обещают дохода. Призовой фонд сезона, если
он объявлен, формируется из выручки проекта и описан в правилах сезона.

- Теги: puzzle, logic, minimalist, offline, solana, cnft, short-session.
- Возрастной рейтинг: 3+ (нет текстов, крови, насилия, азартных механик).
- Языки: русский (основной), английский (нужен для листинга — см. store-copy.en.md).

## Что писать про Solana (Publisher Policy)

В листинге честно указано:

- приложение использует Solana только для выдачи наград (cNFT по стандарту
  Bubblegum/Metaplex);
- кошелёк не требуется для игры; подключение — через Mobile Wallet Adapter
  (Seed Vault Wallet на Seeker, Phantom, Solflare, Backpack);
- игрок не совершает транзакций и не платит комиссий;
- в приложении нет токена, продажи токена, стейкинга, депозитов и любых
  обещаний доходности;
- витрина продаёт косметику (вид), покупка идёт через магазин платформы;
- часть косметики открывается за монеты за игру: они начисляются за собранный
  квартал (20 плюс 10 за каждую звезду, плюс 20 за челлендж дня), за деньги не
  продаются, не покупаются и не выводятся;
- монеты хранятся только на устройстве и ни на что, кроме вида, не влияют; на
  блокчейне выпускаются лишь награды за проверенные сервером решения.

## Ассеты

| Файл | Размер | Где используется |
|---|---|---|
| `assets/icon-512.png` | 512×512 | иконка листинга |
| `assets/feature-graphic-1024x500.png` | 1024×500 | фичер-график |
| `assets/screenshot-1.png` | 1080×1920 | скриншот: игра (уровень 3) |
| `assets/screenshot-2.png` | 1080×1920 | скриншот: пломба и страница реестра (уровень 22) |
| `assets/screenshot-3.png` | 1080×1920 | скриншот: поздний ярус (уровень 63) |
| `assets/screenshot-4.png` | 1080×1920 | скриншот: гардероб — поле с косметикой, купленной за монеты |
| `assets-en/…` | те же размеры | английский набор — его и загружать в dApp Store |

Английский набор рисуется той же командой с флагом:
`python3 store/render_assets.py --lang en`. В нём настоящий английский лор —
и интерфейс, и записи реестра переводятся из канона контента.

Скриншоты отрисованы по настоящим кадрам движка (`npm run store:data` →
`store/data/scenes.json` → `npm run store:assets`), поэтому показывают реальные
уровни, а не художественную постановку на пустом фоне.

Иконка листинга совпадает со знаком внутри приложения (adaptive icon +
`store/assets/icon-512.png` рисуются по одному мотиву: перекрёсток квартала).
