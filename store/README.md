# Витрина: ассеты, тексты, чек-лист

Материалы для публикации Амперграда в dApp Store (Seeker).

| Файл | Что это |
|---|---|
| `listing.md` | тексты листинга: описания, категория, теги, раздел про Solana |
| `privacy.md` | политика конфиденциальности (черновик для юрпроверки) |
| `checklist.md` | пошаговый чек-лист публикации: что готово, что нужно владельцу |
| `assets/` | русский набор: иконка 512×512, фичер-график 1024×500, скриншоты 1080×1920 |
| `assets-en/` | английский набор (язык листинга dApp Store), тот же состав |
| `data/scenes.json` | кадры игры из настоящего движка (данные для скриншотов) |

## Как пересобрать ассеты

```bash
npm run store:data                      # кадры из движка (packages/engine)
npm run store:assets                    # русский набор PNG (требует pillow и DejaVu)
python3 store/render_assets.py --lang en  # английский набор
```

`store:data` считает маски фрагментов, ток и подписи движком, поэтому скриншоты
честно показывают реальные уровни: сцена 1 — уровень 3 «Лицензионный свет» в
процессе, сцена 2 — уровень 22 «Тупик на Виадуке» с пломбой и страницей реестра,
сцена 3 — уровень 63 «Жила № 7» позднего яруса.

Четвёртый скриншот (`screenshot-4.png`) собирается отдельно: движок даёт кадр
уровня 3, а цвета берутся из надетой косметики (`palette-mercury`, `theme-plateau`,
`source-gold`) по тем же правилам, что в приложении — `wardrobe_skin()` повторяет
маппинг `app-android/.../content/Wardrobe.kt`. Так витрина показывает то, что
игрок действительно покупает за монеты.

Иконка листинга и знак в приложении — один мотив (перекрёсток квартала: ток,
память, пломба). В Android он лежит как vector drawable
(`app-android/app/src/main/res/drawable/ic_launcher_foreground.xml`).
