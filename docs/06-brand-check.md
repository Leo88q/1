## 2. Что это значит

- Название свободно в том смысле, которое важно для старта: **никто не
  занимает его как игру, приложение или бренд**, и в выдаче нет соседа, с
  которым «АМПЕРГРАД» можно было бы перепутать в классе игр.
- Общая часть «ампер» (ампер — единица силы тока) описательная. Это минус для
  регистрации знака в чистом виде и плюс для нас как для названия: слово
  объясняет игру, но само по себе не monopolизируемо. Регистрировать имеет
  смысл всё сочетание **AMPERGRAD / АМПЕРГРАД**, а не корень.
- Риск смешения минимален: у соседей (`Ampere`, `Ampersand`, `amper`) другие
  классы (утилиты, гонки, сетевые инструменты) и другой покупатель.

## 3. Что остаётся владельцу (задачи 👤)

1. **Официальные базы ведомств** — то, что внешний поиск не покрывает:
   - USPTO (США): поиск по `tmsearch.uspto.gov` в классах **9** (ПО) и
     **41** (развлечения, игры);
   - EUIPO (ЕС): `euipo.europa.eu/eSearch`;
   - Rospatent (РФ): поиск по «АМПЕРГРАД» в классах 9 и 41 — нужен, если
     русскоязычное название будет в листинге в РФ;
   - WIPO Global Brand Database — одним окном по нескольким странам.
2. **Домены**: проверить и при необходимости занять `ampergrad.com`,
   `ampergrad.io`, `ampergrad.gg`, `ampergrad.ru` (и/или `амперград.рф`).
   Проверка занимаемости — у регистратора: RDAP по `.io`/`.ru` не отвечает,
   а ответ по `.com` через внешние сервисы недоступен из этой среды.
3. **Ники**: X, Telegram, Discord, GitHub — занять одно и то же написание
   (`ampergrad`), чтобы под названием не появился чужой канал.
4. **Юрист**: тексты листинга (`store/listing.md`, `store/listing.en.md`),
   политика конфиденциальности (`store/privacy.md`) и правила сезона с
   призовым фондом — до объявления сезона с призами.
5. **Товарный знак**: если планируется сезон с призами и витрина, подавать
   заявку имеет смысл до публичного релиза (приоритет по дате подачи).
