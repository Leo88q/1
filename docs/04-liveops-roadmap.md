# 04. Live-ops, экономика, виральность и роадмап

## 1. Петли удержания для 1–3 минутной сессии

| Петля | Механика | Награда |
|---|---|---|
| Ежедневная | «Реши 3 уровня» + daily-челлендж (общий seed для всех) | серия/стрик, монеты, cNFT-бейдж за 7/30 дней |
| Недельная | Челлендж недели: фиксированный сложный уровень, рейтинг по ходам | редкий скин, место в зале славы |
| Сезонная (8 недель) | Тематический глава-мир, Battle Pass (free + платный трек), сезонный лидерборд | сезонный cNFT-набор, «страницы лора» (см. 01) |
| Социальная | Кланы (7–12 человек), клановый счёт недели | клановый значок, клановые палитры |
| UGC (v2) | Конструктор уровня с share-кодом/ссылкой | авторские уровни в ротации, «знак автора» |

Важно: всё перечисленное — **необязательное**. Игра остаётся играбельной офлайн, без кошелька и без токена.

## 2. Косметика (витрина NFT)

| Тип | Что это | Канал |
|---|---|---|
| Набор крыльев/плёнок (по 01-C) | палитра + узор + эффект частиц | reward + платно |
| Темы поля (обои) | фон, сетка, звук | платно / за сезон |
| Редкие типы фрагментов | визуальные варианты тройников/крестов | редко в награду |
| Источник питания | «золотая искра», анимированный источник | премиум-тир |
| Достижения | cNFT-печати «Без подсказок», «Минимум ходов», «30 дней» | только наградой |

Цены (ориентир, тестировать): 1.99–4.99 $ за набор косметики; Battle Pass 4.99 $ за сезон; премиум-набор «авторский» 9.99 $. **Никаких pay-to-win механик** — только вид.

**Монеты за игру** (реализовано): 20 за квартал + 10 за каждую звезду, +20 за челлендж дня — то есть 30–50 монет за сессию и примерно 3750 за кампанию из 75 уровней. Монеты не покупаются за деньги и тратятся только в разделе «за монеты»: палитры 450–900, тема 700, сезонный источник 2000. Самый дорогой предмет — примерно 40 собранных кварталов, то есть достижим без единой покупки. Монеты живут только на устройстве: они не продаются, не покупаются и не выводятся, а на блокчейне выпускаются лишь награды за решения, которые сервер проверил ходами игрока. Даже полностью подделанный локальный прогресс даёт максимум другой вид поля — ценности, которую можно было бы продать, у него нет.

Купленный или выданный за игру предмет сразу надевается и меняет вид поля (цвет тока, сетка и фон квартала, шина питания); на правила, время и награды косметика не влияет — это проверяется тестом в контенте и в приложении.

## 3. Монетизация и призовой фонд

- **Без обязательного токена.** Токен не нужен ни для игры, ни для наград; потенциальный utility-токен — только после релиза и только если появится смысл (например, голосование по темам сезона).
- **Источники:** косметика, Battle Pass, rewarded video (по запросу: подсказка/бустер/×2 монет), спонсорские сезоны.
- **Призовой фонд:** только от выручки, публичный отчёт по сезону. Никогда — из депозитов новых игроков. Это принципиальная разница между «мы платим из выручки» и понзи-схемой.
- **Форматы призов:** косметика, ограниченные NFT, физический мерч, USDC-пул на сезон (не более $X, где X — заложено в бюджет). Правила — в ToS, с датами, критериями и налогами на победителе.
- **Реклама:** rewarded video только за бонусы, не за прохождение; никаких принудительных вставок между уровнями (убивает «мгновенный дофамин»).

## 4. Метрики и цели первого сезона

| Метрика | Цель к концу 3-го месяца |
|---|---|
| D1 retention | ≥ 35 % |
| D7 retention | ≥ 12 % |
| Средняя длина сессии | 4–8 минут (2–4 уровня) |
| Конверсия в подключение кошелька | ≥ 25 % от дневной аудитории |
| Средний ARPDAU | 0.02–0.05 $ |
| Crash-free sessions | ≥ 99.5 % |

Дашборд минимум: день/сессия/склонность к подсказкам/доля решённых уровней/доля тех, кто бросил уровень >90 с (это подсказка о кривой сложности).

## 5. Виральность (без спама)

- **Share-карточка** после рекорда: имя игрока, сетка, число ходов, уникальный визуальный узор уровня → картинка в мессенджеры.
- **Подарочный cNFT по ссылке**: генератор ссылки создаёт «капсулу» (один минт), получатель открывает веб-страницу, подключает кошелёк **через Mobile Wallet Adapter в Chrome for Android** и забирает награду. Ссылка одноразовая, отзывается по TTL.
- **Причина поделиться:** редкий узор поля доступен только через ссылку; автор ссылки получает эксклюзивный оттенок того же узора.
- Ограничения: не более N живых ссылок на игрока, антифрод по частоте и устройству (иначе ферма минтов).

## 8. Риски и способы снять

| Риск | Что делать |
|---|---|
| Провал по ретеншену | Ставить плейтест на 9-й неделе, до этого не строить NFT-экономику |
| Спам-минты через клейм | Серверный минт + rate limit + device-bond + KMS-ключи |
| Лицензионная грязь с PipeWalker | Не брать код из тегов ≤ v0.9.5; вести `THIRD_PARTY.md` c SHA коммита |
| Отказ в dApp Store | Publisher Policy: честное описание NFT/наград; APK подписан своим ключом; privacy policy на месте |
| «Ещё один пайп-пазл» | Уникальный мир/имя (01), маскот, ежедневный общий челлендж — это то, что нельзя скопировать из чужого UI |
| Стоимость cNFT в мейннете | Минтить батчами, деревья покупать только под сезон; награды не выдавать по 10 штук на игрока |
