# 05. АМПЕРГРАД — библия мира и бренда

Выбранный концепт: **«АМПЕРГРАД» / AMPERGRAD** (был вариант B в 01).
Проверка имени: в поиске (ru/en) игра с таким названием **не найдена**; ближайшие совпадения — `Trudograd` (ATOM RPG, другое), `Ampersand` (гоночная инди-игра), `Embark` — не пересекаются. Перед релизом — финальная проверка доменов, ников и ТЗ в классах 9/41 (см. чек-лист в 01).

---

## 1. Основа

| Параметр | Значение |
|---|---|
| Название | **АМПЕРГРАД** / **AMPERGRAD** |
| Слоган | «Верни городу ток» / *Bring the current back* |
| Жанр | логическая головоломка на соединение цепей |
| Сессия | 1–3 минуты (1–3 уровня) |
| Тон | сухой регламент гильдии + тихая тревога; «служебная» подача текста |
| Что такое «фрагмент» в мире | участок токопроводящей **магистрали** квартала |
| Что такое «источник» | **шина** / вольт-мастер с искрой |
| Что такое «узел» | **приёмник** квартала (дом, лифт, госпиталь, радиоузел) |
| Победа | **пломба** — контур замкнут, квартал дышит светом |
| Термины, которых не должно быть в UI | `pipe`, `PipeWalker`, «труба», «фитинг» — используем свой словарь |

## 2. Мир

Город **Амперград** построен внутри **Гальванического массива** — гигантской природной аккумуляторной горы. Свет здесь не метафора: это ресурс, который город добывает, хранит в жилах и тратит. Ярусы сверху вниз:

1. **Плато Первого Контакта** — административный верх, туториал. Пальмы на крышах, реклама, солнечный свет «по лицензии».
2. **Ртутный ярус** — мастерские, подпольные ремонтники, «живой» металл.
3. **Терминальный ярус** — транспорт, порты, старые терминалы связи.
4. **Старый Диод** — почти отключенный исторический сектор: здесь учили первого вольт-мастера.
5. **Плавильня (Ядро)** — дно массива, то, ради чего всё гасилось.

Правила мира (даёт геймплейные следствия):
- Свет хранит **память**: включённый квартал «вспоминает» — голоса, записи, чужие дни.
- Включить свет — не значит сделать добро. Часть города построена так, что в темноте ей спокойнее.
- **Гильдия Ключа** отвечает за ток формально; фактически торговля светом идёт через «Ламповую биржу».

## 3. Персонажи и голоса

| Персонаж | Роль | Голос / подача |
|---|---|---|
| **Вольт-мастер (игрок)** | последний практикант гильдии, которого «забыли» в списке отключённых | нет реплик, только действия |
| **«Клемма»** | ИИ-диспетчер гильдии, ваш ассистент | говорит регламентами: «Позиция 4.2: при перегрузке — сброс». Со временем цитирует записи, которых нет в регламенте |
| **Марта Вольт** | наставница, ушла в Ртутный ярус | короткие фразы, радиопомехи, «не входи в Старый Диод» |
| **Госпожа Хриза** | владелица Ламповой биржи | вежливая, торгуется, всегда права и всегда не права |
| **Крючники** (культ «Долга») | антагонисты-правдолюбы: свет — это долг, который город не вернёт | шепчут лозунги в интеркомы, иногда помогают |
| **Плавильня** | то, что находится на дне и просыпается от включённого света | не говорит словами: помехи, ритмы, детские считалки из эфира |

## 4. Сюжетная арка (3 сезона по 8 недель)

- **Сезон 1 «Три квартала».** Заказ прост: починить три квартала Ртутного яруса. Финал: Хриза отказывается платить, «Клемма» находит запись о том, что отключение шло **сверху вниз**, и в архиве не хватает одной страницы.
- **Сезон 2 «Долг».** Крючники выходят из подполья. Они показывают: свет в Амперграде — это выработка людей, чьи дни «сожгли» в жилы. Игрок выбирает, чинить ли госпиталь, который формально уже «оплачен чужими днями».
- **Сезон 3 «Плавильня».** Спуск на дно массива. Три финала: полностью включить город (свет вернётся, память — нет), оставить полумрак (город живёт, правда забыта), отдать ток Крючникам (город уснёт, память уцелеет).

## 5. Структура контента

| Ярус | Уровни | Сетка | Новое правило |
|---|---|---|---|
| Плато | 1–15 | 4×4 → 5×5 | туториал: колено, магистраль, поворот |
| Ртутный | 16–30 | 5×5 → 6×6 | тройники, кресты, отвлекающие тупики |
| Терминальный | 31–45 | 6×6 → 7×7 | два приёмника, ограничение ходов на звезду |
| Старый Диод | 46–60 | 7×7 | «мёртвые» ячейки (залитые стеклом), два источника |
| Плавильня | 61–75 | 7×7 → 8×8 | всё вместе + секретные «записи» |
| Daily | 1/день | по уровню дня | общий seed для всех игроков, рейтинг по ходам |

Боссовые «секции» — 5 уровней с фиксированной вручную схемой (не генератор), сценарные, привязаны к поворотам сюжета.

## 6. Реестр (лор-фрагменты как награды)

60 коротких записей, выдаются как cNFT-«страницы реестра». Формат: 2–4 строки, подпись говорящего, дата в циклах. Каждая запись существует на двух языках (ru — канон, en — рабочий перевод для листинга dApp Store); оба текста лежат в `packages/engine/src/content/lore.ts` рядом, поэтому расхождение видно на ревью.

Примеры:

> **Цикл 419, реестр 3.1.** «Плато вышло на резервный контур в 04:12. Персонал не предупреждён. Считать штатным.» — диспетчер, подпись нечитаема
>
> **Цикл 422, реестр 7.8.** «Марта, я знаю, что ты ушла вниз. Твой пропуск ещё работает. Это плохой знак — пропуска гасят, когда человек мёртв.» — Клемма, отметка: *черновик, не отправлено*
>
> **Цикл 431, реестр 1.1.** «Мне сказали: три квартала, ничего сложного. Я открыл первый — и в жилах услышал свой голос. Запись от 12-го цикла. Я тогда ещё не родился.» — вольт-мастер (ваша строка появится здесь позже)
>
> **Цикл 405, реестр 12.4.** «Свет — это не услуга. Это счёт, который предъявят потомкам.» — Крючник, листовка
>
> **Цикл 388, реестр 9.9.** «Плавильня не спит. Она дышит в такт нагрузке. Сегодня ровно как наше потребление.» — техник, подпись вырезана

## 7. Визуальный стиль и UI

| Элемент | Значение |
|---|---|
| Фон | `#06080E` … `#0B0F1A`, вертикальный градиент + дождь частиц |
| Активный ток | `#00E5C7` (мятный) |
| Металл/без питания | `#243044`, обводка `#3A4A63` |
| Акцент опасности / Крючники | `#FF3D81` |
| Награда / золото | `#FFC24B` |
| Типографика | заголовки — Space Grotesk Bold, текст — JetBrains Mono (моно = «реестр») |
| Тайлы | линия толщиной 6–8 px, свечение через наложение слоёв (blur), скруглённые стыки, разъёмы под 90° |
| Источник | «шина»: две клеммы + пульсирующая искра |
| Приёмник | «пломба»: ромб с глифом квартала |
| Иконка приложения | квадрат-пломба: разомкнутый контур, внутри молния-сдвиг (буква «А» как незамкнутая цепь) |
| Анимация победы | волна тока пробегает по контуру, пауза 0.4 с, «выдох» сети, глиф квартала загорается |

Звук: гул трансформатора (фон), щелчок реле при повороте (обязательно «смачный»), «вдох» при подключении узла, «выдох» при пломбе, один 90-секундный трек на ярус (эмбиент + металлические перкуссии).

## 8. NFT-предметы (что именно минтится)

| Название | Тип | Как получить | Стандарт |
|---|---|---|---|
| **Пломбы** | достижения («Минимум ходов», «Без подсказок», «Сухой ход ×10») | игра | cNFT |
| **Реестр** | страницы лора (60 шт. по сезонам) | сложные уровни, стрик, daily | cNFT |
| **Палитры кварталов** | скины поля: цвет тока, фон, звук | магазин / сезон | cNFT (Core для премиума) |
| **Печати гильдии** | сезонные знаки отличия | Battle Pass, лидерборд | cNFT |
| **Золотая шина** | премиум-источник (анимированная искра) | платно, лимитированный тираж | Metaplex Core |

Лор-описания к предметам — обязательны: каждый предмет — это «запись реестра», а не просто скин (см. 01-C про мотивацию собирать).

## 9. Тон-оф-войс (правила текста)

- Пишем как служебную документацию: коротко, без восторгов, без смайликов.
- Никогда не объясняем игроку лор напрямую — только через реестр, интеркомы и «Клемму».
- Никаких шуток-мемов и отсылок к реальным брендам/политике.
- Ошибки игрока — «штатная перегрузка», не «ты проиграл».
